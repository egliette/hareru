# Youtube Dictation Website

Practicing dictation with youtube videos

## Installation

Install dependencies:

```
pip install -r requirements.txt
```

## Usage

Start server:

```
uvicorn app.server:app --reload
```

Your website will be available at "http://localhost:8000/"
